# 3. API Testing

API testing was performed using **Postman**.

**Charles Proxy** was used to investigate the network traffic generated by the Android application and identify API requests where possible.

### API Testing Flow

```text
Kredily Android App
        ↓
   Charles Proxy
        ↓
Identify API Request
        ↓
      Postman
        ↓
Send Request
        ↓
Verify Response
```

* HTTP methods
* Status codes
* Request parameters
* Response body
* Response structure
* Authentication

# 4. AI-Assisted QA

AI was used to assist with test-case generation and QA analysis.

### AI Tool

ChatGPT

### Prompt Used

```text
Act as a QA Engineer and generate functional test cases
for the Kredily HRMS Android application.

Cover positive, negative, boundary and validation scenarios
for the Attendance module.

Include Test Case ID, Scenario, Preconditions, Steps,
Expected Result and Priority.
```

### AI-Generated Output

The AI-generated test scenarios were reviewed against the actual application.

### What I Changed / Validated

I:

* Removed irrelevant scenarios.
* Added application-specific test cases.
* Verified test steps against the actual UI.
* Added negative and boundary scenarios.
* Corrected expected results where required.
* Validated the generated scenarios manually.

AI-generated assumptions were not treated as actual defects without verification.

# 8. Final QA Summary

The Kredily HRMS application was evaluated through manual functional testing, defect reporting, API testing and AI-assisted test design.

The testing focused on validating application functionality, identifying defects, documenting reproducible issues and verifying application behavior against expected results.

### Key Findings

* Major application workflows were explored and tested.
* Functional test cases were documented.
* Identified defects were documented with reproduction steps and evidence.
* API testing was investigated using Charles Proxy and Postman.
* AI was used to assist test-case generation, followed by manual validation.
* Screenshots and other relevant evidence were collected during testing.

### Overall Assessment

The application requires further testing and defect verification for the issues identified during the testing process. Additional API validation can be performed when complete API documentation, endpoints and authentication details are available.
